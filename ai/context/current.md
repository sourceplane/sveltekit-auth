# sveltekit-auth — where this repository stands

The entry page for anyone (or any agent) picking this repository up. It is
this repository's own state and does not ship to a site built from it; the
two pages that do are [operations.md](operations.md) and
[deployment.md](deployment.md).

## What it is

Auth.js's SvelteKit example (nextauthjs/sveltekit-auth-example, ISC) — a
home page, a sign-in page, a protected page and a sign-out over
`@auth/sveltekit`, with the example's 26 OAuth providers, each offered once
its keys are stored — on SvelteKit 2 and Svelte 5, deployed as one
Cloudflare Worker + Static Assets through SvelteKit's own Cloudflare
adapter. Sessions are Auth.js's encrypted JWT cookies; there is no database.
The AUTH_SECRET is generated on each environment's Worker by its first
deploy. Packaged as an Orun baseline: `orun new --blueprint
repo-blueprint.yaml` builds a new site in its own repository and takes it to
live on stage and prod in one landing (`01-product`), then records what went
live (`03-docs`).
